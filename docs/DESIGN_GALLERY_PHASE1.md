# BNB Design Inspiration Gallery — Phase 1

## Purpose

An image-first inspiration catalogue for early BNB digital-service customers. It deliberately avoids building 18 interactive demo applications before BNB has paying clients.

## Live routes

- `/#gallery` — compact six-category homepage preview, linked to the full gallery.
- `/gallery` — twelve original visual concepts, two for each of the six services.
- `/services?service=<serviceId>&package=custom&reference=<conceptId>#enquiry` — preselected enquiry with a validated design-reference message.

## Experience

- Original first-party SVG preview images live under `frontend/public/gallery`.
- Browse category and visual-style filters and text search on the full page.
- Preview image opens a larger view with a short design explanation, color swatches and a quote CTA.
- All preview cards are labeled design concepts, not completed real client projects, functioning templates or live demos.
- The quote CTA flows into the **existing** MongoDB lead and transactional email workflow; the selected reference is inserted into the requirements field for context.
- Static SVGs are small, self-hosted and avoid third-party image hotlinks or unlicensed website screenshots.
- Design concepts are for illustration; timelines, scope, commercial terms and functionality are agreed individually.

## Curated directions

## Next work when clients request it

- Replace vector concepts with polished user-approved screenshots or original commissioned imagery where useful.
- Create an actual interactive proof-of-concept **only** for a selected high-interest design, not all 12 automatically.
- Add a real portfolio/case-study section only after genuine client deliveries, with explicit permission.

Any published brand/site references should be credited as external inspiration, never presented as BNB client work.
